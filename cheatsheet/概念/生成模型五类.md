# 概念卡 · 生成模型五类：训练、采样、密度、隐变量

**触发：** 题干出现 generative model、exact density／likelihood、VAE、GAN、autoregressive、normalizing flow、diffusion、latent variable、reconstruction、KL、adversarial。

## 分类树

```
生成模型（学 p(x)；判别模型学 p(y|x)）
├── 显式密度（能算 p(x)）
│   ├── 精确：自回归（链式法则连乘）、normalizing flow（变量替换公式）
│   └── 近似：VAE（只有下界 ELBO）
└── 隐式密度（算不出 p(x)，只能抽样）
    ├── 一步：GAN
    └── 多步：diffusion（讲义归隐式；训练用变分界）
```

## 五类对照表

| | 训练目标 | 如何采样 | 精确密度？ | 有无 z | 需要标签？ |
|---|---|---|---|---|---|
| 自回归 | 最大似然；p(x) = ∏ p(x_t \| x_<t)，逐个预测下一个 | 逐个掷骰子 T 步，慢；训练可并行 | **能** | 无 | 否 |
| VAE | 最大化 ELBO = 重建 E[log p(x\|z)] − KL(q(z\|x) ‖ N(0,I)) | z ~ N(0, I) → decoder，一步；**不用 encoder** | 否，下界 | 有，低维 | 否（重建是自监督） |
| GAN | minimax：D 判真假，G 骗 D；交替更新；G 实际用 −log D(G(z)) | z → G，一步，最快 | 否，不建模 | 有 | 否（真假标签自动产生） |
| Normalizing flow | 最大似然；p(x) = p_Z(f(x))·\|det ∂f/∂x\|；f 可逆、Jacobian 好算 | z → f⁻¹，一步；同一网络正算密度反着生成 | **能** | 有，与 x 同维 | 否 |
| Diffusion | 预测噪声 ε，MSE | x_T ~ N(0, I) → 去噪 T 步，慢 | 否（下界） | 有 | 否 |

## 常考点

- **VAE**：encoder 输出分布（μ、Σ），不是一个点；重参数化 z = μ + σ⊙ε 让梯度传过抽样；去掉 KL 退化成自编码器、从 N(0, I) 抽 z 出垃圾；KL 权重过大 z 不带信息。
- **GAN**：D 理想输出真 1 假 0；G 希望 D(G(z)) → 1；均衡时 D 对真假都输出 0.5，p_G = p_data；没有总损失曲线；训练不稳定。
- **自回归**：训练时前缀是真实值所以并行；生成串行；PixelRNN 序列长度要乘通道数（32×32 RGB = 3072）。
- **Flow**：p 小 ↔ |det| 小的地方被 f 拉伸；要求双射；要堆很多层、吃内存。

## 陷阱

- "需要标注数据"对五类都错。
- "VAE 能算精确密度""diffusion 能算精确密度"错。
- 均衡时 D 输出 0.5，不是 1。
- VAE、GAN、flow 生成都是"抽 z → 一个网络 → 整张图"，区别全在训练。
