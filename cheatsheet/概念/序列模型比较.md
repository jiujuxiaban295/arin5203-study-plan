# 概念卡 · RNN、LSTM、self-attention、transformer 比较；位置编码

**触发：** 题干出现 permutation invariant／equivariant、memory efficient、parallel computation、vanishing gradient、LSTM gates、positional encoding／embedding、fixed／random position embedding、self-attention in CNN。

## 四模型表（Q2.6 型）

| | RNN | LSTM | self-attention | transformer（无位置编码） |
|---|---|---|---|---|
| 置换不变（打乱输入顺序，输出不变）？ | 否，h 依赖顺序 | 否 | **是**，输入集合的无序函数 | **是** |
| 内存高效？ | **是**，每步只存固定大小的 h | **是**，多存一个 c | 否，n×n 分数矩阵 | 否 |
| 高度并行？ | 否，第 t 步等第 t−1 步 | 否 | **是**，所有位置同时算，交互距离 O(1) | **是** |
| self-attention 能用在 CNN 里？ | — | — | **能**：non-local block 插进特征图之间；ViT 混合模型用 CNN 特征当 token | — |

扩展列：CNN 不置换不变（平移等变）、内存随 n 线性、可并行；**带位置编码的 transformer 不再置换不变**。

## 各模型一句话

- **RNN**：同一组权重每步重复用，h_t = f(W·h_{t−1} + U·x_t)；h 不断被改写；梯度多步连乘 → 消失，远处依赖学不到；爆炸用 gradient clipping。
- **LSTM**：加 cell state c 和遗忘／输入／输出三个门（sigmoid，0–1）；c 的更新是**加法**（"+ 号是秘密"），遗忘门 1、输入门 0 时信息原样保留；约记 100 步 vs RNN 约 7 步。
- **Self-attention**：每个词当 query 去所有词的 key 里取 value，加权求和；交互距离 O(1)；代价 n²。

## 位置编码

- **为什么要**：self-attention 本身是无序函数（置换不变），不加就不知道词序；在第一层给 x_i 加 p_i。
- **种类**：正弦（固定、不可学）；可学习向量（最常用，不能外推到训练长度以外）；RoPE（旋转，表达相对位置）。
- **固定随机的位置向量能用吗**：**能**。要求只是"同一位置稳定对应同一向量"，随机抽一次后冻住满足；正弦本质也是一组固定向量。
- **每步重新随机能用吗**：**不能**。位置 3 每次不同，不携带信息，等于加噪声。
- invariant vs equivariant：invariant 输出不变；equivariant 输出随输入一起换序。

## 陷阱

- "置换不变"和"需要位置编码"是同一件事的两面。
- RNN／LSTM "内存高效"指不存 n×n 表，不是参数少。
- 位置编码不是正则化、不是防过拟合、不是跨序列算注意力。
