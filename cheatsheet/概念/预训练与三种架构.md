# 概念卡 · 预训练、微调、三种架构、ICL、BPE

**触发：** 题干出现 pretraining、fine-tuning、transfer learning、BERT、GPT、T5、masked LM、encoder／decoder、in-context learning、few-shot、subword、BPE、scaling。

## 预训练＋微调 = transfer learning

```
预训练   海量无标签文本上做语言建模（预测下一个词），存参数；学到语法、事实、常识、推理
微调     用预训练参数当起点，在少量标注的目标任务数据上接着训；"Pretrain once, finetune many times"
好处     复用预训练知识 → 比从头训练数据更少、收敛更快
2017 前  只预训练词向量（无上下文），其余参数随机初始化
```

Q2.9 型英文模板：
> Take a model pretrained with language modeling on a large unlabeled corpus, then fine-tune it on a small labeled dataset for the target task. The model reuses the language knowledge learned in pretraining, so it needs much less data and training time than training from scratch.

## 三种架构

| | Encoder（BERT） | Encoder-Decoder（T5） | Decoder（GPT） |
|---|---|---|---|
| 上下文 | 双向 | 输入双向、输出单向 | 只看左边 |
| 预训练目标 | Masked LM：遮 15%（80% [MASK]、10% 随机词、10% 不变）去预测 | Span corruption：挖掉若干段，decoder 还原 | 预测下一个词 |
| 擅长 | 理解、分类；不擅长生成 | 输入一段出一段（翻译、摘要） | 生成；最大的模型都是 decoder |
| 微调 | 接分类头 | 文本到文本 | 接分类头，或继续当生成器 |
| 规模 | base 110M、large 340M | 220M–11B | 117M → 1.5B → 175B |

口诀：**能看右边就不能考"猜右边"，只能考填空；只能看左边才能考"猜下一个"。**

## In-context learning

- 例子写进 prompt（"thanks → merci，hello → bonjour，otter →"），模型**不更新参数**就按模式输出。
- 例子的作用是**指定任务**；GPT-3 175B 是标志。
- 对比：微调改参数、要梯度、要标注集；ICL 都不要。

## BPE

- 固定词表碰到新词变 UNK。BPE 从字符开始，反复**合并语料里最常相邻的一对**成新子词，直到词表够大。常见词整词，罕见词拆段。GPT 用 40 000 次合并。
- 例：hug、hug、hugs、pug → 先合 (u,g)→"ug"，再合 (h,ug)→"hug"；hugs → hug+s，pug → p+ug。

## Scaling laws

- 模型越大、数据越多，困惑度**可预测地**下降；小模型规律可预测大模型。
- 成本 ≈ 参数 × token；70B 配更多 token 胜过 175B（GPT-3 配比不优）→ **参数与数据要配平**。

## 陷阱

- "BERT 用预测下一个词预训练"错；"GPT 不能做分类"错；"预训练需要标注数据"错。
- 归类题问"最自然"：理解／分类 → encoder。
- "模型越大一定越好、与数据无关""成本只看参数"错。
