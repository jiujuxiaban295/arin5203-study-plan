# 概念卡 · NeRF 与 3D Gaussian Splatting

**触发：** 题干出现 NeRF、radiance field、novel view synthesis、volumetric、Gaussian Splatting、opacity、spherical harmonics。**讲义无**，今年范围待确认；去年各考一道多选。

## 问题

围着一个物体拍了一组稀疏的多视角照片，想渲染**没拍过的角度**（新视角合成）。

## 两种表示

| | NeRF | 3D Gaussian Splatting |
|---|---|---|
| 场景存在哪 | 一个 MLP 的参数里（隐式） | 几十万到几百万个 3D 高斯的属性里（显式） |
| 网络／点的输入输出 | 输入 3D 坐标 + 观看方向 → 输出颜色 + 密度 | 每个高斯：位置、协方差（形状）、**不透明度**、**颜色**（球谐系数，随视角略变） |
| 渲染 | 每像素发一条光线，沿线采样、反复查网络，按密度累加（体渲染） | 把高斯"泼"到图像平面光栅化，按不透明度叠加 |
| 速度 | 慢 | 快，实时 |
| 训练 | 渲染像素与照片比，误差反传到 MLP | 优化每个高斯的属性 |

## 常考点

- NeRF 的坐标**不直接喂**网络，先过位置编码（正弦，和 transformer 同思路），否则出不了高频细节。
- NeRF 从稀疏图像合成新视角；有动态场景（随时间变化）的扩展。
- GS 的颜色和不透明度**挂在每个高斯上**，不是单个固定 RGB、不是纹理图、不是深度图。
