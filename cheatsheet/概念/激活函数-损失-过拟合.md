# 概念卡 · 激活函数、损失函数、过拟合与欠拟合

**触发：** 题干出现 activation function、sigmoid／tanh／ReLU、loss、MSE／cross-entropy、training error／test error、overfitting、dropout、early stopping、data augmentation。

## 激活函数

- 作用：引入非线性；线性激活叠多少层决策边界都是直线。
- 能不能当激活函数，问两条：**非线性？对所有实数有定义？** 2x 线性 ✗；log(x) 在 x ≤ 0 无定义 ✗；ReLU = max(0, x) ✓；sigmoid ✓。

| | 值域 | 零点 | 备注 |
|---|---|---|---|
| Sigmoid 1/(1+e⁻ˣ) | (0, 1) | 0.5 | 当概率用 |
| Tanh | (−1, 1) | 0 | |
| ReLU | [0, ∞) | 0 | 负数变 0；神经元"开／关"是非线性来源 |
| Leaky ReLU | 分段线性 | 0 | 分段线性 ≠ 线性，不能化简 |

## 损失函数

- **MSE** (y − ŷ)²：回归、输出任意实数。
- **二元交叉熵**：输出 0–1 概率；真实 1 时预测 0.9 → 0.11，预测 0.1 → 2.30。

## 先诊断再开药

| 信号 | 诊断 |
|---|---|
| 训练误差一直降、测试误差先降后升 | **过拟合**（背答案） |
| 训练误差和测试误差都高且接近 | **欠拟合**（学不动） |

| 手段 | 过拟合时 | 欠拟合时 |
|---|---|---|
| 模型大小／深度 | 减小，别再加 | **加大** |
| Dropout、weight decay | **加** | 减 |
| 训练时间 | **early stopping** | 训练更久 |
| 数据增强 | **有用** | 通常没用，甚至更难学 |
| 激活函数 | — | 线性换成非线性 |

## 陷阱

- 同一个选项（如"加深网络"）会因题干是过拟合还是欠拟合而对错反转，先判断是哪种。
- 数据增强让训练变难，治"学太多"，不治"学不动"。
- log(x) 在 0 也没定义。
