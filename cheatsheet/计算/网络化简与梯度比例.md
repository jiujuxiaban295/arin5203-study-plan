# 计算卡 · 线性隐藏层网络的化简与梯度比例

**触发：** 题干给一个带隐藏层的小网络，隐藏层激活 h(z) = c·z（或别的），输出 g = sigmoid，问 P(y=1|x) 的展开式 A + Bx₁ + Cx₂、等价的无隐藏层网络、能否化简的理由、∂L/∂w 的比例。**周六必练**。

## 步骤：化简

1. **代入**：把每个隐藏单元的 z 整个代进 h：h(z₁) = c·(w₁ + w₃x₁ + w₅x₂)，三项都乘 c。
2. **拆括号**（分配律），再代进输出单元的 z。
3. **合并同类项**：常数项归 A，x₁ 的系数归 B，x₂ 的系数归 C。
4. 画等价网络：输入 1、x₁、x₂ 直接连输出单元，权重 A、B、C，输出单元标 g。

```
通用形：输出 z = w₇ + w₈·h(z₁) + w₉·h(z₂)，z₁ = w₁ + w₃x₁ + w₅x₂，z₂ = w₂ + w₄x₁ + w₆x₂，h(z) = c·z
A = w₇ + c·w₈·w₁ + c·w₉·w₂
B = c·w₈·w₃ + c·w₉·w₄
C = c·w₈·w₅ + c·w₉·w₆
P(y=1|x) = g(A + Bx₁ + Cx₂)
```

## 能否化简的判据

- **线性激活（h(z) = cz，或 cz + d）：** 能。线性满足 h(a+b) = h(a) + h(b)、h(ka) = k·h(a)，隐藏层输出是输入的加权和加常数，再加权仍是加权和，层数再多也一样，整网等价于无隐藏层的 g(线性函数)。常数 d 并入 A。
- **分段线性（ReLU、Leaky ReLU）或任何非线性：** 不能。LeakyReLU(4 + (−6)) = −0.2 ≠ LeakyReLU(4) + LeakyReLU(−6) = 3.4，括号拆不开，整网非线性，无隐藏层网络只能表示 g(线性函数)。**分段线性 ≠ 线性。**

英文模板：
> (Yes) A linear activation satisfies h(a+b) = h(a) + h(b) and h(ka) = k·h(a), so each hidden unit outputs a linear combination of the inputs plus a constant; the next layer takes a linear combination of these, which is again linear in the inputs. Repeating layer by layer, the network collapses to g(w̄₀ + w̄₁x₁ + w̄₂x₂), a network with no hidden layer.
> (No) Leaky ReLU is piecewise linear but not linear, e.g. LeakyReLU(4 + (−6)) ≠ LeakyReLU(4) + LeakyReLU(−6), so the hidden layer cannot be merged and the whole network is nonlinear.

## 步骤：梯度比例

对任何一个权重 w，它把输入 u 送进某个单元的 z：**∂L/∂w = (∂L/∂z)·u**。同一个单元的所有入边共享 ∂L/∂z，所以它们的梯度之比就是**各自输入之比**。

```
w₁、w₃、w₅ 都进 z₁，输入分别是 1、x₁、x₂
∂L/∂w₁ : ∂L/∂w₃ : ∂L/∂w₅ = 1 : x₁ : x₂       与损失函数、激活函数无关
```

若问不同单元的权重之比（如 w₈ : w₉），要分别算 ∂L/∂z，不能套这条。

## 陷阱

- 参数 c 写小写，别和系数 C 混。
- 拆括号最容易漏偏置项。
- 化简后的网络以 x₁、x₂ 为输入，不是以 h(z₁)、h(z₂) 为输入。
- 等价网络图输出单元要标 g。
