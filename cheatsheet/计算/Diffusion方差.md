# 计算卡 · Diffusion 正向过程的方差与均值

**触发：** 题干给 q(x_t | x_{t−1}) = N(x_t; √(1−β_t)·x_{t−1}, β_t·I)，问 Var(x_t)、E[x_t]，或改成 x_{t−1} 方差不为 I、问多步后。

## 步骤

1. 把分布改写成代数式：**x_t = √(1−β_t)·x_{t−1} + √β_t·ε，ε ~ N(0, I)，与 x_{t−1} 独立。**
2. 当作一个像素算，最后补 I。
3. 三条规则：**系数平方**（Var(aX) = a²Var(X)）；**独立相加方差相加**；**常数方差 0**。
4. 写出中间一步再给结论，不要只写"方差保持"。

## 公式

```
Var(x_t) = (1−β_t) · Var(x_{t−1}) + β_t · I
E[x_t]   = √(1−β_t) · E[x_{t−1}]
旧方差 I  →  (1−β_t)·I + β_t·I = I           （方差保持，所以 x_T ≈ N(0, I)）
旧方差 σ²I →  [(1−β_t)σ² + β_t]·I
多步闭式：ᾱ_t = ∏_{s≤t}(1−β_s)，x_t = √ᾱ_t·x₀ + √(1−ᾱ_t)·ε，ᾱ_T → 0
```

## 例

- β = 0.1，Var(x_{t−1}) = I → I；E = √0.9·μ ≈ 0.949μ。
- β = 0.1，Var(x_{t−1}) = 4I → 0.9·4 + 0.1 = 3.7I。
- β₁ = 0.1、β₂ = 0.2，Var(x₀) = I → Var(x₂) = I；ᾱ₂ = 0.72，x₂ = √0.72·x₀ + √0.28·ε。

## 陷阱

- I 是单位矩阵当方差：每个像素方差 1、互不相关；答案带 I。
- 系数是 √(1−β)，方差里变成 (1−β)，别忘平方。
- 两项必须独立才能相加；题目默认 ε 是新抽的。
