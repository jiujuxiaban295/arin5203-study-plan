# 计算卡 · 矩阵求导（反向传播型短答）

**触发：** 题干给 f(x) = W₂·ReLU(W₁x) 之类的小网络和损失 L = ‖f(x) − y‖²，要 ∂L/∂x、∂L/∂W₁、∂L/∂W₂；或给 ReLU 在 0 处梯度约定。**周六必练**，卡只用来核对。

## 步骤

1. **标形状。** x (n×1)，W₁ (m×n)，a = W₁x (m×1)，z = ReLU(a) (m×1)，W₂ (k×m)，f = W₂z (k×1)，y (k×1)，L 标量。
2. **定约定。** 用行向量约定：标量对列向量的导数写成行向量 (1×n)，链式法则从左往右乘。全程一致。
3. **逐层写局部导数**，按形状链相乘，最后核对结果形状。
4. **ReLU 的导数是 mask。** ∂z/∂a = diag(1[a > 0])，题目说"输入为 0 时梯度为 0"就按此。

## 公式

```
基本规则（行约定）
  ∂(aᵀx)/∂x = aᵀ            ∂(Ax)/∂x = A            ∂(xᵀAx)/∂x = xᵀ(A + Aᵀ)
  ∂‖u − y‖²/∂u = 2(u − y)ᵀ    ∂ReLU(a)/∂a = diag(a > 0)   （diag(z > 0) 同义，z 与 a 同号）

模板：L = ‖W₂ ReLU(W₁x) − y‖²
  ∂L/∂x  = 2(f − y)ᵀ · W₂ · diag(z > 0) · W₁        形状 (1×k)(k×m)(m×m)(m×n) = 1×n ✓
  ∂L/∂W₂ = 2(f − y) · zᵀ                            (k×1)(1×m) = k×m ✓
  ∂L/∂W₁ = [diag(z > 0) · W₂ᵀ · 2(f − y)] · xᵀ      (m×1)(1×n) = m×n ✓
```

列约定（结果写成列向量）就是把上面整体转置：∂L/∂x = 2·W₁ᵀ·diag(z > 0)·W₂ᵀ·(f − y)。两种都对，**一题之内别混**。

## 例

x = (1, −1)ᵀ，W₁ = [[1, 0], [1, 1]]，W₂ = [1, 2]，y = 0。a = (1, 0)ᵀ，z = (1, 0)ᵀ（0 处 ReLU 输出 0、梯度 0），f = 1。
∂L/∂x = 2·1·[1, 2]·diag(1, 0)·W₁ = 2·[1, 0]·[[1, 0], [1, 1]] = [2, 0]。

## 陷阱

- 形状对不上就是乘序错了，先写形状链再填内容。
- diag(z > 0) 放在 W₂ 和 W₁ 之间，不是最前或最后。
- 2 别丢；y 不是函数，∂y/∂x = 0。
- 题目若给 ReLU 零点约定，照抄，不自己定。
