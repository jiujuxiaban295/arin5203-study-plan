# 计算卡 · CNN 输出尺寸、参数量、感受野

**触发：** 题干出现 kernel／filter 大小、stride、padding、feature map 尺寸、receptive field、参数个数。

符号：输入边长 N，输入通道 C，核边长 F，核个数 K，步长 S，补边 P。

## 步骤

1. 把 N、C、F、K、S、P 六个数抄在纸上，缺哪个看题目有没有默认（no padding → P = 0；没说 stride → S = 1）。
2. 判断问的是**图多大**（输出尺寸）、**几个数**（参数量）还是**一个点看到多大**（感受野）。
3. 代公式；带 padding 必须带 2P；参数量别忘 +1 bias。

## 公式

```
① 输出尺寸      (N + 2P − F) / S + 1      除不尽：讲义说"不合法"，框架向下取整
                输出通道 = K  →  输出 W₂ × H₂ × K
② 保持尺寸      S = 1 且 P = (F − 1)/2     F3→P1，F5→P2，F7→P3
③ 参数量        (F · F · C + 1) · K        与图片长宽无关；1×1 卷积 (C + 1)·K
④ 池化          尺寸同 ①（P = 0）；通道不变；参数 0；2×2 S2 长宽减半
⑤ 感受野（全 S=1）  r = 1 + Σ(Fᵢ − 1)     同尺寸 L 层：1 + L(F − 1)
                倒推验证：从输出 1 开始每往前一层加 (F − 1)
⑥ 感受野（含步长／池化）  起点 r = 1, j = 1；每层 r ← r + (F − 1)·j，然后 j ← j·S
```

## 例

- 32×32×3，10 个 5×5，S1，P2 → 32×32×10；参数 (5·5·3 + 1)·10 = 760。
- 56×56×64，128 个 3×3，S1，P1 → 56×56×128；参数 (9·64 + 1)·128 = 73 856；输入换 224 参数不变。
- 4 层 3×3 S1 → 1 + 4·2 = 9；4 层 5×5 S1 → 1 + 4·4 = 17。
- 3×3 S1 → 2×2 池化 S2 → 3×3 S1：r 1→3→4→8。
- 30×30、F7、无 padding、步长未知：S=1→24，S=2→12.5（取整 12），S=3→8.67，S=4→6.75，S=5→5.6，S=6→4.83；"哪些可能"按取整判断。

## 陷阱

- 有 padding 漏 2P（第 2 天唯一一次错）。
- 参数量写成 C·F·F + C；正确是 (F·F·C + 1)·K。
- 输出尺寸和感受野方向相反，别混。
- "第 4 个非图像层" = 第 4 个卷积层的输出。
- 递推时先用旧 j 算 r，再更新 j。
