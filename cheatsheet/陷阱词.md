# 多选陷阱词卡

> 每道多选逐个选项判断，每项写一句理由；"整题全对才算对"。先找题干在问哪个概念，再用下面两类词过筛。

## 一、看到这些词先怀疑（通常错）

| 词 | 为什么 | 例 |
|---|---|---|
| only / solely / exclusively | 把能力说死 | "多模态 LLM 只靠文本训练""ViT 只做分类" |
| requires / must / need labeled data | 生成模型、预训练都不要标签 | "VAE 需要标注数据""预训练需要标注" |
| guarantees / optimal in all scenarios | 没有方法保证最优 | "DPO 保证最优" |
| random / rule-based / without learning | 说的是不学的东西 | "reward model 随机给分""手写规则" |
| eliminate the need for data | 任何微调都要数据 | "instruction tuning 不需要数据集" |
| less data than CNN / than supervised | 方向反了 | "ViT 比 CNN 更少数据"（ViT 更吃数据） |
| regularization / prevent overfitting / inject noise（说位置编码） | 位置编码只负责顺序 | |
| exact density（说 VAE、GAN、diffusion） | 精确密度只有自回归、flow | |
| CFG + GAN / VAE | CFG 只用于逐步去噪模型 | |
| classifier（说 CFG） | CFG 恰恰不要分类器 | |

## 二、看到这些说法通常对（能力陈述偏宽不算错）

- "can process / can generate / can be used for …"：描述能力范围，范围宽一点是对的（多模态 LLM 能处理和生成文本、图像、动作；ViT 也能做检测、分割；self-attention 可用于 CNN）。
- "improves performance on tasks involving multiple types of data"。
- "learns a probabilistic mapping to a latent space"（VAE）；"loss includes reconstruction and KL"（VAE）。
- "adversarial training between two networks"（GAN）。
- "patches as tokens like words"（ViT）；"represents position because self-attention has no built-in position information"。
- "simplifies training by removing the need for reward functions"（DPO）；"predicts human preference"（reward model）；"binary preferences"（DPO）。
- "adapt to specific datasets while maintaining general-purpose ability"（instruction tuning）。

## 三、题干反转要重判

- 过拟合（训练降、测试升）vs 欠拟合（都高）：对策几乎相反，先诊断。
- "只给 Q/K/V" vs "包含投影"：复杂度 O(n²d) vs O(n²d + nd²)。
- "固定随机位置向量" vs "每步重新随机"：能 vs 不能。
- "线性激活" vs "分段线性"：能化简 vs 不能。
- "x_{t−1} 方差 I" vs "σ²I"：I vs [(1−β)σ² + β]I。

## 四、做题纪律

1. 每项写理由；不写理由两次栽在 Q1.5 式的题上。
2. 同一题挑一个选项改成相反说法再判断一次，确认理解不是背字母。
3. 单题超过 4 分钟先跳过，标记回头。
