# 第 2 天速查表 · CNN 输出尺寸、参数量、感受野

> 对应 [第 2 天详细计划](第2天-CNN输出尺寸与感受野.md)。去年考试为开卷，本页可作为打印资料；今年规则以教师通知为准。依据 Lecture 5 PDF 第 75–90、100–103 页。

符号：输入边长 N（或 W1×H1），输入通道 C，核边长 F，核个数 K，步长 S，补边 P。

```
① 卷积输出尺寸     W2 = (W1 + 2P − F) / S + 1       除不尽时向下取整（讲义口径：该设置不合法）
                   H2 同理；输出通道 = 核个数 K        → 输出 W2 × H2 × K

② 保持尺寸不变     S = 1 且 P = (F − 1)/2             F=3→P=1，F=5→P=2，F=7→P=3

③ 卷积层参数量     F × F × C × K  +  K（bias）        与图片长宽无关

④ 池化层           输出尺寸同 ①，P = 0；通道数不变；参数量 = 0
                   2×2、S=2 → 长宽各减半

⑤ 感受野（全部步长 1、无池化）
                   r = 1 + Σ(Fᵢ − 1)                  同尺寸 L 层：1 + L(F − 1)
                   倒推验证：从输出 1 开始，每往前一层加 (F − 1)

⑥ 感受野（含步长或池化的通用递推）
                   起点 r = 1, j = 1
                   每过一层：r ← r + (F − 1) × j ，然后 j ← j × S
                   池化按 F=窗口、S=步长代入
```

## ⑥ 算例

结构：3×3 卷积 S=1 → 2×2 池化 S=2 → 3×3 卷积 S=1

| 层 | F | S | r | j（更新后） |
|---|---|---|---|---|
| 起点 | | | 1 | 1 |
| 卷积 | 3 | 1 | 1 + 2×1 = 3 | 1 |
| 池化 | 2 | 2 | 3 + 1×1 = 4 | 2 |
| 卷积 | 3 | 1 | 4 + 2×2 = 8 | 2 |

一维验证：第 1 层 a1 用 p1–p3，a2 用 p2–p4……；池化 b1 = max(a1,a2) 覆盖 p1–p4，b2 覆盖 p3–p6，b3 覆盖 p5–p8；第 3 层 c1 由 b1 b2 b3 算出，覆盖 p1–p8，共 8 个像素。

## 易错点

- 有 padding 就必须带 2P，不要算成无补边的结果。
- 选择题"哪些输出尺寸可能"：若按整除一个选项都凑不出，就按向下取整判断。
- 参数量每个核要 +1 个 bias，再乘核个数。
- 输出尺寸是"图多大"，感受野是"一个点看到多大"，方向相反。
- "第 4 个非图像层"= 第 4 个卷积层的输出。
- 2025 Q2.3 / Q2.4 是 ⑤ 的直接应用；Q1.6 是 ① 加取整判断。
