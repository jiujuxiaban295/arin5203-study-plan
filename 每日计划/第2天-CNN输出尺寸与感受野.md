## ③ 练习

**再做变化题（自编，答案见文末）：**

1. 输入 64×64，单个 5×5 卷积核，S = 2，P = 2。输出空间尺寸？
2. 输入 32×32×3，16 个 3×3 卷积核，S = 1，P = 1。输出体积与参数量（含 bias）？
3. 输入 56×56×64，128 个 3×3 卷积核，S = 1，P = 1。输出体积与参数量？再换成 32 个 1×1 卷积核，参数量是多少？参数量和 56 这个数有关系吗？
4. 四层卷积、全部 S = 1、无池化：前三层 3×3，第四层 5×5。第四层神经元相对输入图像的感受野？
5. 三层 3×3 卷积，步长依次为 1、2、1，无池化。第三层相对输入的感受野？与三层全部 S = 1 相比大了多少？
6. 对 32×32×16 的特征图做 2×2 最大池化，S = 2。输出体积与可学习参数量？
7. 结构：3×3 卷积（S=1）→ 2×2 最大池化（S=2）→ 3×3 卷积（S=1）。最后一层相对输入的感受野？

**变化题 5、7 需要的通用公式：** 第 l 层相对输入的感受野 r_l = r_{l−1} + (K_l − 1)·j_{l−1}，其中 j 是累计步长（jump），j_l = j_{l−1}·S_l，初始 r_0 = 1、j_0 = 1。所有层 S = 1 时退化为讲义第 85 页的 1 + Σ(K_l − 1)。

## ④ 整理：当天要写清的易混点

- **输出尺寸 vs 感受野**：前者问特征图多大，用 (N + 2P − F)/S + 1；后者问一个输出像素"看到"多少输入像素，用 1 + Σ(K − 1)·jump。两者方向相反，不能混用。
- **参数量只和 F、C、K 有关**，与输入的 H×W 无关；每个卷积核的参数是 F·F·C + 1（bias）。池化层参数为 0。
- **不整除怎么办**：讲义口径是"不能应用"，PyTorch 口径是向下取整。做选择题时两种口径都要能解释，并按题目措辞判断。
- **计数口径**："第 4 个非图像层"是指第 4 个卷积层的输出；padding 不改变感受野大小，只改变边界处感受野落在图外的部分。

## 自查答案（做完再看）

1. (64 + 4 − 5)/2 + 1 = 31.5 + 1 → 向下取整得 **32×32**。
2. (32 + 2 − 3)/1 + 1 = 32 → **32×32×16**；参数 3·3·3·16 + 16 = **448**。
3. **56×56×128**；参数 3·3·64·128 + 128 = **73 856**。1×1 卷积：64·32 + 32 = **2 080**。参数量与 56 无关。
4. 1 + 2 + 2 + 2 + 4 = **11×11**。
5. r 依次为 3 → 3 + 2·1 = 5 → 5 + 2·2 = **9×9**；全部 S = 1 时为 7×7，大 2。
6. (32 − 2)/2 + 1 = 16 → **16×16×16**；参数 **0**。
7. 卷积后 r = 3、j = 1；池化后 r = 3 + 1·1 = 4、j = 2；再卷积 r = 4 + 2·2 = **8×8**。
