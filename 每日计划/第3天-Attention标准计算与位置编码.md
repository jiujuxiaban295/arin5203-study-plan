## ② 零基础讲解：8 个积木块

每块给出：讲什么 → 讲义页 → 即时小题。小题答案在文末自查区。

### 第 0 块 · 矩阵乘法形状规则（今天所有计算的地基）

- **讲什么：** (a×b) 矩阵乘 (b×c) 矩阵，结果是 (a×c)；中间的 b 必须相同。结果的第 i 行第 j 列 = 左矩阵第 i 行与右矩阵第 j 列做点积（对应相乘再相加）。算一次这样的乘法要做 **a·b·c** 次乘法，这个数就是后面"复杂度"的来源。
- **讲义页：** 无，用[矩阵求导补充材料](https://github.com/jiujuxiaban295/arin5203-study-plan/releases/download/course-materials-2026-10-25/MatrixCalculus.pdf)第 1 页的记号即可。
- **即时小题 0：** A = [[1, 2, 0], [0, 1, 3]]（2×3），B = [[1, 0], [2, 1], [0, 2]]（3×2）。求 AB 的形状和数值，并说出一共做了多少次乘法。

### 第 1 块 · token 与 embedding：句子变成矩阵

- **讲什么：** 每个词（token）先变成一个长度为 d 的向量 x_i（embedding）。n 个词叠起来就是矩阵 X，形状 **n×d**：一行一个词，一列一个特征维度。考题里 "sequence length n、embedding dimension d" 指的就是这两个数。
- **讲义页：** L4 第 40 页前两行。
- **即时小题 1：** Q2.10 的题干里 n 和 d 各是多少？X 的形状是什么？

### 第 2 块 · Attention 的直觉：按相似度加权求和

- **讲什么：** 给一组 value 向量和一个 query 向量，Attention 就是**对 value 做加权求和，权重由 query 和每个 key 的相似度决定**（L4 第 35 页原话）。类比图书检索：query 是你要找的问题，key 是每本书的标签，value 是书的内容；标签越像你的问题，这本书的内容在答案里占的比重越大。
- **讲义页：** L4 第 35 页。
- **即时小题 2：** 若 query 与 key₁ 的相似度远大于与 key₂ 的相似度，输出接近哪个 value？权重之和是多少？

### 第 3 块 · Self-attention 三步：Q、K、V 从同一句话来

- **讲什么：** 对每个词 x_i：① 用三个 d×d 矩阵投影 q_i = Q·x_i，k_i = K·x_i，v_i = V·x_i；② 算相似度 e_ij = q_i·k_j（点积），对 j 做 softmax 得到权重 α_ij（非负、一行加起来等于 1）；③ 输出 output_i = Σ_j α_ij v_j。"self" 的意思是 q、k、v 都来自同一个序列。
- **讲义页：** L4 第 40 页。
- **即时小题 3：** softmax 之前的分数是 (2, 0)，softmax 之后的权重约是多少？（提示 e² ≈ 7.39）

### 第 4 块 · 矩阵形式与缩放：一行公式算完整句

- **讲什么：** 把 n 个词一起算：XQ、XK、XV 都是 **n×d**；分数矩阵 (XQ)(XK)ᵀ 是 **n×n**（第 i 行第 j 列 = 词 i 对词 j 的分数）；output = softmax((XQ)(XK)ᵀ)·(XV) 是 **n×d**。原论文在分数上除以 **√d_k**（d_k 是 q、k 的维度）：维度越大点积越大，softmax 会变成接近 one-hot、梯度消失，缩放就是把分数压回合理范围。
- **讲义页：** L4 第 58 页（矩阵形式）、第 61 页（Scaled Dot Product）。
- **即时小题 4：** n = 10、d = 512，写出 XQ、分数矩阵、输出的形状。分数矩阵里一共有多少个数？

### 第 5 块 · 复杂度：数一数做了几次乘法（Q2.1 的全部内容）

- **讲什么：** 用第 0 块的 a·b·c 规则数：
  - 投影 XQ：(n×d)(d×d) → **n·d²**，K、V 同理，共 3nd²
  - 分数 (XQ)(XK)ᵀ：(n×d)(d×n) → **n²·d**
  - 加权求和 softmax(·)(XV)：(n×n)(n×d) → **n²·d**
  - 合起来 **O(n²d + nd²)**。多头时每个头是 n²·(d/h)，h 个头加起来仍是 n²d，所以 h 不出现在大 O 里。
  - 讲义第 77 页只写 O(n²d)，那是**只数分数矩阵**、默认 n ≫ d；考题特别说明"不假设 n ≫ d"，就要把投影的 nd² 也写上。
- **讲义页：** L4 第 60、75、77 页。
- **即时小题 5：** 如果题目已经直接给了 Q、K、V 三个 n×d 矩阵（不需要投影），复杂度是多少？

### 第 6 块 · 多头与参数量（Q2.10 的全部内容）

- **讲什么：** 多头 = 用 h 组不同的 Q_ℓ、K_ℓ、V_ℓ 各算一遍 attention，每组把 d 维压到 **d/h** 维（矩阵形状 d×(d/h)），h 个头的输出拼回 d 维，再过一个 d×d 的输出矩阵 Y 混合。
  - **参数量 = 矩阵里的数字个数 = 行数×列数。** 一个头：3 个 d×(d/h) 矩阵 → 3·d·(d/h)；h 个头 → **3d²**（h 约掉了）。加输出矩阵 Y → **4d²**。
  - **参数量与序列长度 n 无关。** Q2.10 里的 "10 tokens" 是干扰项，和第 2 天"参数量与图片长宽无关"是同一个道理。
  - 去年官方答案**只算 Q、K、V、不含输出矩阵和 bias**。考试时按题目口径算，并一句话写明"不含 bias 与输出投影"。
- **讲义页：** L4 第 59–60 页。
- **即时小题 6：** d = 512、h = 8，每头 Q、K、V 都是 512×64。一个头多少参数？8 个头多少？与 3d² 相等吗？

### 第 7 块 · 位置编码：self-attention 看不见顺序

- **讲什么：** 第 3 块的三步里没有任何一步用到"词 i 排在第几位"，把句子打乱，每个词的输出不变（这叫置换不变）。解决办法：给每个位置 i 造一个 d 维向量 p_i，**加到** x_i 上：x̃_i = x_i + p_i，只在第一层加一次。两种常见做法：正弦函数（固定、不可学，周期性）；可学习的位置向量（每个位置一列，最常用，但不能外推到训练没见过的长度）。RoPE 只记名字："用旋转表达相对位置"。
- **讲义页：** L4 第 41–44 页（第 45–47 页 RoPE 看标题即可）。
- **即时小题 7：** Q1.8 的四个选项逐项说对错及理由。

### 第 8 块 · ViT：把图片切成 patch 当 token

- **讲什么：** 把图片切成 p×p 的小块（patch），每块拉直成一个向量（3·p·p 个数），线性投影到 D 维，加上可学习的位置向量，再加一个专门用于分类的 class token，然后**原封不动**送进 NLP 的 Transformer。224×224 图、16×16 patch → 14×14 = 196 个 token。数据量：只在 ImageNet（120 万张）上训练时 ViT 不如 ResNet，在 JFT-300M（3 亿张）预训练后才反超，所以 ViT **更吃数据**。ViT 不只做分类，也做检测、分割。
- **讲义页：** L6 第 40–49 页（结构）、53–57 页（数据量）、112 页（总结）。
- **即时小题 8：** 224×224 的图，patch 改成 32×32，有多少个 token？每个 patch 拉直后多少个数？

## ④ 整理：当天要写清的易混点

- **"已给 Q/K/V 的 Attention 运算" vs "包含投影的计算"：** 前者只有分数 (n×n) 和加权求和两步，复杂度 O(n²d)；后者多了 XQ、XK、XV 三次投影，多出 nd²，参数量也全在投影矩阵里。题目说"直接给出 Q、K、V"就不算投影。
- **复杂度看 n，参数量不看 n：** 复杂度 O(n²d + nd²) 里 n 出现两次；参数量 3d²（或 4d²）里没有 n。"10 tokens" 之类的序列长度只影响计算量和分数矩阵大小，不影响参数个数。
- **h 在哪里出现：** 每头维度 d/h、矩阵形状 d×(d/h) 用到 h；加总后大 O 和参数量都把 h 约掉了。
- **位置编码是"加上去"，不是"乘上去"，也不是正则化：** 它只提供顺序信息，Q1.8 的 (a)(b) 把它说成防过拟合或稳定训练都是错的。
- **ViT 的 token 是 patch，不是像素：** 224/16 = 14，不是 224。
