## A 段 · 矩阵求导：Q2.5 的全部内容（Lecture 2 第 48–53 页；数学补充）

Lecture 2 第 48–53 页是图片，PDF 搜不到文字，考场上查不了；这一段的目标是**不看卡也能写出形状链**。先用一维标量把链式法则说清，再升到向量和矩阵，每一步只多加一个规则。

### 第 0 块 · 一维链式法则：导数就是"每一段的放大倍数相乘"

- **讲什么：** 一个最小的网络：a = w₁·x，z = ReLU(a)，f = w₂·z，L = (f − y)²。x 变一点，a 跟着变 w₁ 倍，z 跟着变 ReLU′(a) 倍（a > 0 时 1，a < 0 时 0），f 跟着变 w₂ 倍，L 跟着变 2(f − y) 倍。总放大倍数就是四段相乘：

```
dL/dx = dL/df · df/dz · dz/da · da/dx = 2(f − y) · w₂ · ReLU′(a) · w₁
```

  每个因子叫**局部导数**，只看相邻两层。这就是第 1 天没讲的"链式求导每一层乘的是什么"：乘的是**权重**（线性层）、**激活函数的导数**（激活层）、**损失的导数**（最后一层）。
- **ReLU 的导数：** ReLU(a) = max(0, a)，a > 0 时斜率 1，a < 0 时斜率 0，a = 0 处题目会给约定（通常取 0）。ReLU 关着的时候，整条链的导数是 0，这叫"梯度被 mask 掉"。
- **讲义页：** L2 第 10–13 页（激活函数）、第 48–53 页（反向传播，图片）。
- **即时小题 0：** x = 2，w₁ = −1，w₂ = 3，y = 1。(a) 算 a、z、f、L 和 dL/dx。(b) 把 w₁ 改成 1 再算一遍。两次结果为什么差这么多？

### 第 1 块 · 多个输入时导数是一排数：形状规则

- **讲什么：** 输入变成向量 x = (x₁, …, x_n)ᵀ 时，L 对每个 x_i 各有一个导数，一共 n 个数。**约定**：标量对列向量的导数写成**行向量**（1×n），叫行约定；写成列向量（n×1）叫列约定。两种都对，一题之内只能用一种。今天全程用行约定，因为链式法则可以**从左往右按顺序乘**。
- **形状规则：** p 维向量对 q 维向量的导数是 p×q 矩阵（Jacobian），第 i 行第 j 列是 ∂(输出_i)/∂(输入_j)。链式法则就是把这些矩阵按顺序乘，第 0 块的乘法形状规则（第 3 天第 0 块：(a×b)(b×c) = a×c）保证中间维度对得上。**形状对不上就是乘序错了。**
- **讲义页：** [MatrixCalculus.pdf](https://github.com/jiujuxiaban295/arin5203-study-plan/releases/download/course-materials-2026-10-25/MatrixCalculus.pdf) 开头的记号部分。
- **即时小题 1：** x 是 4×1，W₁ 是 3×4，W₂ 是 2×3，y 是 2×1。写出 a = W₁x、z = ReLU(a)、f = W₂z 的形状，再写出 ∂L/∂f、∂f/∂z、∂z/∂a、∂a/∂x 四个因子的形状，验证乘起来是 1×4。

### 第 2 块 · 三条矩阵规则：全部用分量推一次

- **讲什么：** 考试只用三条，每条都能用 2 维分量 3 秒推出来：

```
① u = aᵀx = a₁x₁ + a₂x₂      ∂u/∂x₁ = a₁，∂u/∂x₂ = a₂   →  ∂(aᵀx)/∂x = aᵀ         （1×n）
② u = Ax，第 i 行 u_i = (A 的第 i 行)·x，对 x 的导数就是 A 的第 i 行  →  ∂(Ax)/∂x = A   （m×n）
③ L = ‖u − y‖² = Σ(u_i − y_i)²，∂L/∂u_i = 2(u_i − y_i)   →  ∂‖u − y‖²/∂u = 2(u − y)ᵀ （1×k）
```

  规则 ② 说明：**线性层的局部导数就是它的权重矩阵**，和第 0 块的 w₁ 一样。规则 ③ 里 y 是常数，∂y/∂x = 0。若损失写成 ½‖u − y‖²，系数 2 消掉。
- **讲义页：** 两份数学补充中关于 Ax、xᵀAx 的规则按需查。
- **即时小题 2：** a = (3, −1)ᵀ，x = (x₁, x₂)ᵀ。(a) 写出 aᵀx 和它对 x 的导数。(b) A = [[1, 2], [0, −1]]，写出 Ax 的两个分量和 ∂(Ax)/∂x。(c) u = (1, 4)ᵀ，y = (0, 2)ᵀ，∂‖u − y‖²/∂u？

### 第 3 块 · ReLU 对向量：导数是一个对角 mask

- **讲什么：** z = ReLU(a) 逐元素作用，z_i 只和 a_i 有关，所以 Jacobian 非对角线全是 0，对角线是每个分量的 ReLU′：1 或 0。写成 **diag(1[a > 0])**，口头叫 **mask**。z 和 a 同号，所以写 diag(z > 0) 是同一个东西。
- **它在链里的位置：** 夹在 W₂ 和 W₁ 之间，不在最前也不在最后——因为它是中间那一层的局部导数。
- **即时小题 3：** a = (3, −1, 0.5, −2)ᵀ。写出 z 和 ∂z/∂a。若题目约定 ReLU 在 0 处梯度为 0，a = (0, 2)ᵀ 时 mask 是什么？

### 第 4 块 · 把形状链串起来：Q2.5 的模板

- **讲什么：** L = ‖W₂·ReLU(W₁x) − y‖²，记 a = W₁x，z = ReLU(a)，f = W₂z。四个局部导数按第 0 块的顺序相乘：

```
∂L/∂x = ∂L/∂f · ∂f/∂z · ∂z/∂a · ∂a/∂x
      = 2(f − y)ᵀ · W₂ · diag(a > 0) · W₁
形状   (1×k)   (k×m)   (m×m)     (m×n)  = 1×n ✓
```

  **做题顺序：** ① 先算前向，把 a、z、f 的数值写出来；② 写形状链，核对最终形状；③ 填数字。写表达式时把 diag 的内容按实际 a 的符号填成 0／1。
- **列约定版本**（结果写成列向量）就是整体转置：∂L/∂x = 2·W₁ᵀ·diag(a > 0)·W₂ᵀ·(f − y)。题目若指定了约定就照办。
- **讲义页：** L2 第 48–53 页（图片）。
- **即时小题 4：** x = (2, 1)ᵀ，W₁ = [[1, −1], [−2, 1]]，W₂ = [1, 1]（1×2），y = 3。先算 a、z、f、L，再算 ∂L/∂x，核对形状。

### 第 5 块 · 对权重求导：梯度 = "这一层的 δ" × "这一层的输入"ᵀ

- **讲什么：** 对 W₂ 求导时，f = W₂z 里 z 是常数，∂L/∂W₂ 的形状必须和 W₂ 一样（k×m）。结果是一个**外积**：把损失传到 f 的梯度写成列向量 δ₂ = 2(f − y)（k×1），乘上这一层输入的转置 zᵀ（1×m）。对 W₁ 同理，只是 δ 要先往回多传两层：

```
δ₂ = 2(f − y)                        (k×1)        ∂L/∂W₂ = δ₂ · zᵀ          (k×m)
δ₁ = diag(a > 0) · W₂ᵀ · δ₂          (m×1)        ∂L/∂W₁ = δ₁ · xᵀ          (m×n)
通用规则：某层权重的梯度 = 该层输出端的梯度（列向量）× 该层输入ᵀ
```

  这条规则就是 Q3(e) 的根：一个权重的梯度 = 它所在单元的 δ × 它自己的输入。B 段会直接用。
- **即时小题 5：** 用第 4 块的数字算 ∂L/∂W₂ 和 ∂L/∂W₁，核对形状和 W₂、W₁ 一样。

### 第 6 块 · 梯度比例：同一个单元的权重，梯度之比就是输入之比

- **讲什么：** 用 A 段第 5 块的规则。z₁ = w₁·1 + w₃·x₁ + w₅·x₂，三个权重都进同一个单元 z₁，所以它们**共享**同一个 ∂L/∂z₁（记作 δ₁）：

```
∂L/∂w₁ = δ₁ · 1        ∂L/∂w₃ = δ₁ · x₁        ∂L/∂w₅ = δ₁ · x₂
∂L/∂w₁ : ∂L/∂w₃ : ∂L/∂w₅ = 1 : x₁ : x₂
```

  δ₁ 在比值里约掉，所以**结论与损失函数、输出激活 g、隐藏激活 h 的形式都无关**——只要 δ₁ ≠ 0。
- **什么时候不能套：** 问的权重进的是**不同单元**（如 w₁ 和 w₂），δ₁ ≠ δ₂，要分别算：δ₁ = δ_out·w₈·h′(z₁)，δ₂ = δ_out·w₉·h′(z₂)。
- **ReLU 的特殊情况：** 若 h = ReLU 且 z₁ < 0，h′(z₁) = 0，δ₁ = 0，三个梯度全是 0，比例无意义。
- **讲义页：** L2 第 23–24 页（结构）、第 48–53 页（反向传播图示）。
- **即时小题 6：** x = (2, −3)。∂L/∂w₁ : ∂L/∂w₃ : ∂L/∂w₅ = ？换成 x = (0, 5) 呢？哪个权重的梯度变成 0，为什么？

- A3：∂L/∂x = 2(f − y)ᵀ·W₂·diag(σ(a) ⊙ (1 − σ(a)))·W₁。a = (0, 0)ᵀ 时 σ = 0.5，σ′ = 0.25，对角矩阵 = 0.25·I。sigmoid 的导数处处大于 0（最大 0.25），不会像 ReLU 那样把某个分量完全 mask 成 0，但很大或很小的 a 会让梯度变得很小。
- A4：x = (1, 2)ᵀ 时 a = (1 − 2, −2 + 2) = (−1, 0)ᵀ，mask = diag(0, 0)，z = 0，f = 0，∂L/∂x = 2(0 − 3)·[1, 1]·diag(0, 0)·W₁ = **[0, 0]**。题目没给约定时，答题先写一句"we take ReLU′(0) = 0"再算，不能默认读者知道。
- A5：(a) 错，顺序颠倒，(1×k)(m×n) 乘不起来，且 mask 应在 W₂、W₁ 之间；(b) 错，zᵀ·2(f − y) 形状是 (1×m)(k×1)，k ≠ m 时根本乘不了，k = m 时得标量，而 ∂L/∂W₂ 必须是 k×m，正确的是 2(f − y)·zᵀ；(c) 对，这是列约定，等于行约定结果的转置。

- B1：三个权重都进 z₂，输入 1、x₁、x₂ → **1 : 2 : −3**，与 Q3(e) 同形。
- B2：w₇、w₈、w₉ 都进输出单元，输入分别是 1、h(z₁)、h(z₂)。B0 权重、x = (2, −3)：z₁ = 0 + 2·2 + 1·(−3) = 1，h(z₁) = 3；z₂ = 1 + (−1)·2 + 0 = −1，h(z₂) = −3。比例 **1 : 3 : −3**。
